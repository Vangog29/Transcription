# Инструкция по сборке Sales Intelligence Pro в .EXE

После того как вы протестировали программу и убедились, что транскрибация и аналитика работают, вы можете собрать её в готовый файл для Windows.

## 1. Подготовка
Убедитесь, что все библиотеки установлены:
```powershell
pip install customtkinter groq google-genai pyinstaller
```

## 2. Сборка через готовый скрипт
В папке проекта я создал файл `build_exe.bat`. 
1. Просто запустите его двойным щелчком мыши.
2. Откроется окно консоли, начнется процесс компиляции (это может занять 1-3 минуты).
3. Когда появится надпись "Build Complete", нажмите любую клавишу.

## 3. Где найти готовую программу?
После сборки в папке проекта появятся две новые папки: `build` и `dist`.
- Ваша программа находится здесь: `dist/SalesIntelligencePro/`
- Главный файл для запуска: `SalesIntelligencePro.exe`

## 4. Что входит в сборку автоматически
Благодаря обновленному скрипту `build_exe.bat`, в папку `dist/SalesIntelligencePro/` автоматически копируются:
1.  **`ffmpeg.exe`** и **`ffprobe.exe`** (необходимы для обработки аудио).
2.  **`analytics_prompt.md`** (файл с системным промптом).

Вам остается только:
- Добавить ваши файлы с ключами (`api_kay_groc.md`, `api_kay_google.md`) в эту папку, либо просто настроить их через интерфейс программы при первом запуске.

## 5. Перенос на другой компьютер
Чтобы передать программу коллеге, просто **заархивируйте всю папку `dist/SalesIntelligencePro`** и отправьте её. Он сможет запустить `.exe` файл без установки Python.
