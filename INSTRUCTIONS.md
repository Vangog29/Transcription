# Инструкция по использованию Sales Intelligence Pro

**Sales Intelligence Pro** — это профессиональный инструмент для автоматизации контроля качества звонков. Он объединяет возможности API Groq для мгновенной транскрибации и API Google (Gemma 4) для глубокой аналитики текста.

---

## 1. Подготовка к работе

### Получение API ключей
Для работы приложения вам понадобятся два ключа:
1.  **Groq API Key**: [Получить здесь](https://console.groq.com/keys) (для транскрибации).
2.  **Google AI API Key**: [Получить здесь](https://aistudio.google.com/) (для аналитики Gemma 4).

### Установка (для разработчиков)
Если вы запускаете проект из исходного кода:
```powershell
pip install -r requirements.txt
```

---

## 2. Использование приложения

### Вкладка "Настройки"
При первом запуске перейдите во вкладку **Настройки**:
1.  Укажите пути к текстовым файлам с вашими ключами (или создайте их в папке программы: `api_kay_groc.md` и `api_kay_google.md`).
2.  Укажите путь к файлу системного промпта (`analytics_prompt.md`). В этом файле прописаны критерии, по которым ИИ будет оценивать звонок.
3.  Нажмите **"Сохранить и применить"**.

### Вкладка "1. Транскрибация"
1.  Нажмите **"Выбрать файл"** и укажите аудиозапись звонка (поддерживаются .wav, .mp3, .m4a, .flac).
2.  Нажмите **"РАСШИФРОВАТЬ ЗВОНОК"**.
    *   *Примечание: Если файл больше 25 МБ, программа автоматически сожмет его для соответствия лимитам API.*
3.  После завершения текст появится в окне. Его можно отредактировать вручную или нажать **"СОХРАНИТЬ ТЕКСТ"**.

### Вкладка "2. Аналитика LLM"
1.  Когда текст звонка готов, перейдите на эту вкладку.
2.  Вы увидите текущий системный промпт. Его можно изменить прямо здесь (изменения не перезапишут основной файл, если не нажать "Сохранить").
3.  (Опционально) Введите дополнительные вопросы к этому конкретному звонку в нижнее поле.
4.  Нажмите **"ЗАПУСТИТЬ ПОЛНЫЙ АНАЛИЗ GEMMA 4"**.
5.  Полученный отчет можно сохранить кнопкой **"СОХРАНИТЬ ОТЧЕТ"**.

---

## 3. Особенности и советы

*   **Авто-сжатие**: Приложение использует встроенные утилиты FFmpeg для подготовки аудио. Вам не нужно устанавливать их отдельно, если они лежат в папке с программой.
*   **Логи**: Если что-то идет не так (например, ошибка API), проверьте вкладку **"Логи"**. Там отображается техническая информация.
*   **Промпты**: Качество анализа на 90% зависит от вашего промпта в `analytics_prompt.md`. Используйте его для задания четких критериев оценки (например, "Проверил ли менеджер потребность?", "Был ли вежлив?").

## 4. Сборка (для администраторов)

Для создания переносимой версии (.exe) используйте файл:
```powershell
build_exe.bat
```
Результат будет в папке `dist/SalesIntelligencePro`.
