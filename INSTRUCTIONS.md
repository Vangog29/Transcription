# Инструкция по использованию Whisper RU Transcriber

Этот проект позволяет транскрибировать аудиофайлы в текст на русском языке с использованием модели `whisper-small-ru-v2` локально.

## 1. Подготовка окружения

Для работы приложения необходим Python 3.10+ и установленные библиотеки.

### Установка зависимостей
Выполните в терминале:
```powershell
# Установка PyTorch (основной движок)
pip install torch transformers accelerate

# Установка библиотек для интерфейса и аудио
pip install customtkinter librosa

# Установка упаковщика (для создания .exe)
pip install pyinstaller
```

*Примечание: Также должен быть установлен [FFmpeg](https://ffmpeg.org/).*

## 2. Запуск приложения

### Консольный тест (проверка работы)
Служит для быстрой проверки модели и замера скорости:
```powershell
python transcribe_test.py
```
*Убедитесь, что в папке лежит файл `test.wav` или измените путь в коде.*

### Графический интерфейс (GUI)
Основное приложение с выбором файлов и сохранением:
```powershell
python transcribe_gui.py
```

## 3. Работа с моделью

### Использование локальной папки
Если вы скачали модель на жесткий диск:
1. Запустите GUI.
2. Нажмите кнопку **"Выбрать папку"** рядом с полем "Модель/Путь".
3. Выберите папку, содержащую файлы модели (config.json, pytorch_model.bin и т.д.).
4. Нажмите "Начать транскрибацию".

### Автоматическое скачивание
Если оставить значение `artyomboyko/whisper-small-ru-v2`, программа сама скачает модель при первом запуске (около 1 ГБ).

## 4. Сборка в .exe файл

Чтобы создать исполняемый файл для Windows:

```powershell
pyinstaller --noconfirm --onedir --windowed --name "WhisperTranscriber" --collect-all "customtkinter" --collect-all "transformers" --collect-all "torch" --collect-all "librosa" "transcribe_gui.py"
```

После завершения в папке `dist/WhisperTranscriber` появится файл `WhisperTranscriber.exe`.

### Рекомендации по сборке:
- Итоговая папка будет весить ~2-3 ГБ, так как включает в себя библиотеки глубокого обучения.
- При первом запуске .exe на другом компьютере может потребоваться установка FFmpeg в систему.
